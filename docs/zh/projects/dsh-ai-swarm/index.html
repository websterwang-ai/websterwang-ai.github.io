01 / 为什么做

DSH-AI-Swarm 是 DeepSeek Harness 的开源插件。给它一个目标，它会拆成有先后关系的任务，交给不同角色的智能体并行推进；看板能看到每一步的进度和审核情况。根据我提供的数据，最近一个月下载量约 6,000 次。

02 / 为什么做

为什么做

多智能体一起做复杂任务，最怕分工和进度说不清。这个插件把任务、依赖关系和审核步骤都摆到明处。

03 / 项目亮点

项目亮点

  • ↗按任务依赖安排并行工作
  • ↗给不同角色配置模型和审核步骤
  • ↗用看板和流程图跟踪进度

如何参与
