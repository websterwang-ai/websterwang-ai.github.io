01 / 出发点

为什么做

申请学校时，公开信息不少，贴近自己情况的建议却不好找。PeerVine 想把学生和有亲身经历的导师连起来，让选择更有底。

02 / 实际用途

项目亮点

  • ↗平台已有 50 多位认证导师
  • ↗可以聊选校和申请准备
  • ↗和过来人一对一交流

03 / 一起参与

如何参与

正在准备申请？先找位导师聊聊。如果你也走过这条路，欢迎加入导师团队。
